# Academic Calendar

A simple yet powerful academic calendar for students, helping you manage exams, projects, assignments, and activities efficiently.

## Features

### 1. Monthly Calendar View
- Displays days and weeks in an organized format.
- Highlights the current day with a distinctive color.
- Shows colored dots for days with events.

### 2. Add & Manage Events
- Add new events like exams, projects, assignments, or activities.
- Set deadlines for each event.
- Edit or delete events easily.

### 3. Notifications & Alerts
- Sends a notification **3 days before the deadline**.
- Warns if an event deadline has passed.
- Notifies you when an event’s deadline is extended.

### 4. Extend Deadlines
- Safely extend deadlines with confirmation prompts.
- Ensures new dates are after the original date.

### 5. Event Organization
- Upcoming events are listed in a dedicated section.
- Completed events are moved to a separate section.
- Overdue events are highlighted with a special color.

### 6. Data Storage
- All data is stored locally using **Local Storage**.
- Events remain saved even after refreshing the page.
